# 408 考研复习资料

在线访问：https://hyosungsink.github.io/408/

- 首页：`index.html`
- 计算机系统机制图谱（组成原理 ⇄ 操作系统）：`system.html`
- 操作系统考点分布表：`os.html`

`system.html` 把组成原理与操作系统合起来看：两科的 1361 分按机制而非科目归入 10 个机制域，
并逐题列出 30 道「分值记在组成原理、解题需要操作系统」的真题。数据结构与计算机网络各自自成
体系，不并入该图谱。

GitHub Pages 发布源为 `main` 分支的仓库根目录。更新该目录中的网页并提交后，网站会自动重新发布。

新增其他科目的 HTML 文件时，可在 `index.html` 中添加对应入口。操作系统页面保留原始文件内容。
